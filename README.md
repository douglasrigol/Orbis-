# Orbis-
Site conceitual de relógios com 3D e animações
Landing page de uma marca fictícia de relógios, com um relógio 3D como protagonista. A rolagem controla a câmera e os textos, o logotipo é desenhado com animação de traço, e uma seção mostra a hora ao vivo em cidades do mundo. Projeto autoral de direção de arte e interação, sem preços nem vendas.
Habilidades: React, Vite, GSAP, Three.js, JavaScript, CSS, WebGL
